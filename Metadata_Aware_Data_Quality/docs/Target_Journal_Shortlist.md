# Target Journal Shortlist

Facts below were verified via live web search on 2026-09-13 against each publisher's
own current pages. Verify again immediately before submission, since APCs, page
limits, and policies can change. No impact factor, quartile, or acceptance-rate
claims are made here unless they were directly and currently confirmed — none were,
so none are stated; check Journal Citation Reports / Scopus yourself at submission time.

## 1. ACM Journal of Data and Information Quality (JDIQ) — strongest scope fit
- **Scope:** explicitly covers data/information quality, provenance, lineage, trust,
  understandability — a near-exact match for this manuscript's topic.
- **Article types:** research, experience, survey, and challenge papers; research
  papers up to 23 single-spaced pages excluding references (25 after revision).
- **Review:** double-anonymous; JDIQ targets a 3-month turnaround.
- **Open access:** as of 1 January 2026, ACM became a fully Open Access publisher;
  all ACM journals (including JDIQ) are now 100% OA. Check ACM's OA page for current
  APC rates, waivers, and discounts before submitting.
- **Format:** ACM authoring template (LaTeX or Word).
- **Source:** dl.acm.org/journal/jdiq (author guidelines, call for papers), accessed 2026-09-13.

## 2. Information Systems (Elsevier)
- **Scope:** design and implementation of languages, data models, and process models
  for data-intensive applications — a good structural fit for the schema/contract/
  metadata framing of this paper.
- **Cost route:** subscription route available with **no mandatory publication fee**
  (article available to subscribers only); optional open-access route currently
  listed at USD 3,150 (may be reduced at submission for some authors/institutions).
- **Source:** sciencedirect.com/journal/information-systems, accessed 2026-09-13.

## 3. Journal of Big Data (Springer Nature)
- **Scope:** broad — all aspects of data science and big data, including data
  capture/storage, architectures, and data-intensive computing.
- **Cost route:** fully open access; **mandatory APC**, currently listed at
  £1,440 GBP / $2,290 USD / €1,990 EUR (subject to tax); waivers available for
  authors in the lowest-income countries per Springer Nature policy, and
  case-by-case waiver requests are considered for others if made at submission.
- **Source:** link.springer.com/journal/40537/submission-guidelines, accessed 2026-09-13.

## Recommendation
Given the exact scope match and reasonable page limit, **ACM JDIQ** is the
strongest first choice. **Elsevier Information Systems** is a strong second choice
specifically because of its no-mandatory-fee subscription route. Re-read each
journal's *current* Guide for Authors / author guidelines in full immediately
before formatting the final submission package — do not rely on this shortlist
beyond initial venue selection.
